# Interstellar Experience 0.2.0 — клиентский прототип Тессеракта

Это новый клиентский проект для Minecraft Java 1.21.11 + Fabric. Он полностью заменяет старую архитектуру с пользовательским измерением.

## Важно: чего эта версия делает и чего не делает

Эта версия **не добавляет новое измерение и не меняет мир**. Она работает как клиентский визуальный мод, поэтому его можно запускать на одиночном мире и на серверах без установки мода на сервере.

Во время игры мод считывает только загруженную клиентом область поверхности рядом с игроком (17×17 колонок), сохраняет до 9 цветовых отпечатков с интервалом примерно 10 секунд и показывает их в интерфейсе Тессеракта как 3×3 временные окна. Есть анимированная графика Гаргантюа и синтезированная русская озвучка фразы. Отпечатки хранятся в памяти и сбрасываются при выходе из мира/сервера.

Это **первый визуальный прототип**, а не точная 3D-реконструкция сцены: в нём пока нет покадрового воспроизведения всех блоков, мобов, игроков, сундуков/Block Entities и настоящего перемещения по 3D-временным копиям мира. Он не может восстановить действия, которые произошли до установки мода.

## Управление

- `O` — открыть/закрыть Тессеракт.
- `P` — вручную сохранить текущий отпечаток мира.
- `←` / `→` или `A` / `D` — переключать временные слои.
- `R` — повторить синтезированную голосовую фразу.
- `Esc` — закрыть экран.

Автоматический отпечаток делается примерно раз в 10 секунд. Первичный отпечаток создаётся при входе в мир.

## Сборка через GitHub Actions

1. Создайте резервную копию текущего репозитория.
2. Замените содержимое репозитория файлами из этого ZIP (папка `.github` должна попасть в корень).
3. Откройте вкладку **Actions** и запустите **Build Interstellar Experience**.
4. После успешной сборки скачайте артефакт `InterstellarExperience-Fabric-1.21.11-v0.2.0`.
5. Удалите старый `interstellar_experience-*.jar` из папки `mods` и положите новый JAR.

Требуется Minecraft 1.21.11, Fabric Loader 0.19.x, Java 21 и Fabric API 0.141.x для 1.21.11.

## Безопасность и совместимость

- В `src/main/resources` намеренно нет `data/<namespace>/dimension_type` и других пользовательских datapack/registry JSON. Это сделано, чтобы не повторить ошибку старой версии, из-за которой клиент не мог загрузить сохранения.
- Мод не отправляет пакеты на сервер, не использует команды сервера и не меняет блоки.
- Клиент видит только чанки, которые сервер/игра уже отправили клиенту. Поэтому на сервере это локальный визуальный эффект только для владельца мода.
- `spawn 1.21+.zip` для этой версии не нужен: мод наблюдает за тем миром, в котором вы сейчас играете.
