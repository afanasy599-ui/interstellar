# Interstellar Experience — Fabric 1.21.11

Первая собираемая версия мода: измерение `interstellar:tesseract`, переход по командам, ночная атмосфера и вращающиеся частицы вокруг игрока.

## Команды в игре

- `/tesseract enter` — перейти в Тессеракт на тех же координатах, что и в исходном измерении.
- `/tesseract exit` — вернуться в сохранённую точку входа (в пределах текущей игровой сессии).
- `/tesseract quote` — вывести фразу на русском языке.
- `/tesseract info` — справка.

## Состав проекта

- Minecraft Java Edition **1.21.11**
- Fabric Loader **0.19.3**
- Fabric API **0.141.4+1.21.11**
- Java **21**
- Yarn mappings **1.21.11+build.6**

## Сборка через GitHub Actions

1. Создай пустой репозиторий GitHub.
2. Распакуй этот архив и загрузи **содержимое папки проекта** в корень репозитория (вместе с `.github`).
3. Открой вкладку **Actions** и разреши запуск workflow, если GitHub попросит.
4. Запусти **Build Interstellar Experience** через **Run workflow**.
5. В завершившемся запуске скачай артефакт `InterstellarExperience-Fabric-1.21.11`.
6. Положи полученный JAR в `.minecraft/mods`. Для игры нужен Fabric Loader 1.21.11 и Fabric API 0.141.4+1.21.11.

## Подготовленный мир

Отдельный архив `Interstellar_Tesseract_World.zip` содержит сохранение `spawn` как обычный мир и копию его файлов `region`, `entities` и `poi` в измерении `dimensions/interstellar/tesseract`. Распакуй папку `Interstellar_Tesseract` в `.minecraft/saves`.

Сначала установи Fabric и мод, затем открой этот мир. После загрузки выполни `/tesseract enter`.

## Важные ограничения первой версии

- Копия измерения создаётся из сохранённых файлов мира на момент упаковки. Это не синхронизируемое зеркало: изменения основного мира после создания архива не переносятся автоматически.
- Инвентари/профили игроков из `playerdata` остаются в сохранении, но другие игроки не превращаются в движущиеся призрачные копии.
- Возврат хранится в памяти текущей игровой сессии. После перезапуска можно вернуться командой `/tesseract exit` на спавн, если точка входа не сохранена.
- Визуальная «чёрная дыра» и настоящая гравитационная линза — следующий этап; эта версия уже добавляет тёмное измерение, кольца частиц и космическую атмосферу.
- Перед открытием любого серверного сохранения в одиночной игре сохрани исходный архив отдельно.

## Безопасность

Оригинальный архив не изменяется. Готовый мир и его копия измерения лежат в отдельном архиве.
